TAQUIRUME – SITO WEB

Pagina di presentazione di Taquirume, l'app universale per note a mano, disegno e produttività (iPad con Apple Pencil, Mac, Windows e Web).

FILE INCLUSI

taquirume-sito.html: il sito, una pagina unica con tutto dentro lo stesso file.
taquirume.html: il prototipo web dell'app (lavagna, penne, colori, pagine).

SEZIONI DEL SITO

	1.	Presentazione iniziale, con titolo, descrizione e pulsanti "Prova il prototipo" e "Scopri le funzioni".
	2.	Funzioni: 8 schede, divise tra "Disponibile nel prototipo" e "In arrivo".
	3.	Piattaforme: iPad con Apple Pencil, Mac, Windows, Web.
	4.	Roadmap: dal prototipo web all'app nativa Apple, fino a cloud e collaborazione.
	5.	Invito finale a provare l'app e piè di pagina.

COME USARLO

In locale: fai doppio clic su taquirume-sito.html e si apre nel browser. Non serve installare nulla.
Online: carica il file su un hosting statico (Netlify, Vercel, GitHub Pages, ecc.) e rinominalo index.html.

COME PERSONALIZZARLO

Link al prototipo: nel file cerca https://claude.ai/artifact/EB4oSvMugjqXyDriUxZUKE e sostituiscilo con taquirume.html, se vuoi usare la copia locale. I due file devono stare nella stessa cartella.
Colori: sono all'inizio del file, nella parte di stile.
Testi e schede: modificali nella sezione "funzioni" dell'HTML.
Anno e nome nel piè di pagina: ultima riga del file.

CARATTERISTICHE TECNICHE

File unico, senza dipendenze esterne e senza JavaScript.
Si adatta a telefono, tablet e computer.
Tema chiaro e scuro automatico, in base alle impostazioni del dispositivo.
Compatibile con notch e barra inferiore di iPhone e iPad.

STATO DEL PROGETTO

Il prototipo include penne, evidenziatore, gomma, forme perfette, colori, pagine infinite con sfondi diversi e salvataggio locale. In arrivo: audio sincronizzato, OCR, attività e Pomodoro, cronologia versioni, app nativa con PencilKit e sincronizzazione cloud.
